# 安居尺度：房价收入比网页

## 范围与口径

网页位于 `docs/index.html`，为无需后端、无外部运行依赖的静态页面。官方数据均为**2024年、中国大陆31省级地区**。不提供全国城市级实时房价；省均价不能代表省会、小区或单套住房。

- 房价：房地产开发企业新建商品住宅平均销售价格，元/平方米。不是二手房挂牌价，也不是70城价格指数。
- 收入：城镇居民人均可支配收入，元/人/年，不是就业人员平均工资。
- 默认情景：90平方米、1人单独购房，按个人可支配收入计算；人数可调整。家庭人口包含未就业成员，不能写成挣钱人数。
- 房价收入比 = 单价 × 面积 ÷ (人均年可支配收入 × 家庭人口)。展示单位为“倍”，不代表实际攒钱或还贷年数。
- 全国参考值使用官方全国价格10419元/平方米与全国城镇居民收入54188元/人/年，不是31省比值的简单平均。默认约17.30倍。

## 来源与复核

国家统计局《中国统计年鉴2025》：

1. [19-11 按用途分新建商品房平均销售价格](https://www.stats.gov.cn/sj/ndsj/2025/html/C19-11.jpg)，住宅列。
2. [6-24 分地区城镇居民人均可支配收入](https://www.stats.gov.cn/sj/ndsj/2025/html/C06-24.jpg)，2024列。
3. [19-9 按用途分新建商品房销售面积](https://www.stats.gov.cn/sj/ndsj/2025/html/C19-09.jpg)，住宅列。
4. [19-10 按用途分新建商品房销售额](https://www.stats.gov.cn/sj/ndsj/2025/html/C19-10.jpg)，住宅列。

逐行读取并复核两张主表；用销售额(亿元) ÷ 面积(万平方米) × 10000，复算31省住宅价格。与官方均价的最大差为0.7839元/平方米，来自原表舍入。原表留存在 `data/raw/`，结构化记录含每条来源、统计期与校验差。核对日期：2026-10-23。

地图原始边界为[阿里云DataV GeoAtlas全国省级数据](https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json)，原始文件留存于 `data/china-provinces.geojson`。投影为Albers等积投影，按上北下南、左西右东绘制，并保持横纵比例一致；南海诸岛单列示意小窗。港澳台没有本次同口径数据，灰色表示未覆盖而非零。

## 交互

- 地图或散点图选择地区，指标切换。
- 全国比较面积、家庭人口联动；最多3地区对比。
- 地区搜索、区域筛选、排序、完整表格及带来源CSV导出。
- 自填住宅单价、面积、家庭月收入，计算总价、收入倍数、首付、从零积累首付年数、等额本息月供与月供收入占比。
- 首付比例、结余率、贷款年限与利率均为用户假设，不表示当前银行利率或贷款政策。未计税费、收入变化、生活开支变动、投资回报或购房资格。
- 月供计算支持零利率、全款；结余为0且首付不为0时展示无法积累，不展示无穷大。
- 个人收入不上传、不持久存储，也不进入分享链接；只在当前浏览器内计算。

## 维护与验证

```sh
python3 scripts/prepare_affordability.py
node --check docs/core.js
node --check docs/app.js
node --test tests/affordability.test.cjs
# 可选：离线DOM模拟（不是原生浏览器）
npm install --prefix tests/dom --no-save --package-lock=false jsdom@26.1.0
node tests/affordability-dom.cjs
# 本地查看
python3 -m http.server 8766 --bind 127.0.0.1 --directory docs
```

更新数据时，先保存新的官方原表和来源，然后调整JSON数据及统计年度；同步更新页面明确写出的年份、官方全国值和本说明，不能只改抓取日期充当新数据。

此次原生浏览器本地访问被权限设置拒绝，因此不声称完成真实浏览器或手机视觉验收。采用数学单元测试、数据校核、离线DOM检查与静态资源检查验证；上线状态另通过部署结果与HTTP响应确认。
