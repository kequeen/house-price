# 中国城市官方数据

入口：`cities.html`。本页将城市级住宅交易、公开区县/镇街明细和同年收入比放在一起，并始终保留原文期间、住宅类型与发布部门。没有用省级均价替代普通地级市。

页面默认筛选2025—2026年，记录按统计期间末尾倒序。旧分享链接仍保留指定记录；如当前筛选已有更新期间，会显示“切换到最新记录”。交易年份和年度收入比基准年份分别选择，年度基准默认最近有资料的年份，并直接说明缺失字段，避免把2024年的完整值呈现为2025年的数据。2026年全年尚未结束，月度、季度、年内累计保持原频率。

## 数值与口径

字段 `houseType` 区分新建住宅、二手住宅、新房及二手住宅合计、全部一手商品房以及未拆分的全类型房屋交易。全部商品房可能含办公、商业和车位，不能当成住宅。`frequency` 保留月度、季度、年度和年内累计；不把累计数写成单月，也不直接相加不同频率。

金额与面积仅在同一条、同一住宅用途、同一来源和期间配齐时计算均价。房价收入比另外要求城市与收入年度一致：

`房价收入比 = (住宅销售金额元 / 同口径住宅销售面积㎡) × 情景面积㎡ / (同年城镇人均年可支配收入元 × 家庭人口)`

默认90㎡、1人。家庭人口不是挣钱人数。均价是开发企业住宅销售统计的平均值，不是目标楼盘报价。统计局销售与住建网签是不同口径，不能把南京住建新房套数与统计年鉴金额/面积拼成一条交易记录。北京是直辖市，原有全国年鉴中的北京行本身就是城市范围，并非以河北或其他省份的均价估算。

各条缺失保持null，前端显示“—”。只有套数/面积时不生成价格；缺区县收入时不生成区县收入比。原表用万套或万平方米舍入发布后，换算成基本单位不意味着获得了逐套精度。中山PDF带#条目保留 `isComponent=true`，显示为拆分项，不与其父分组加总。

## 采集与维护

来源注册表：`configs/city-sources.json`。

- 白名单仅包含已经登记的官方HTTPS站点。读取有超时和10MB上限，不自动跟随重定向。
- 北京、武汉、石家庄以及上海年鉴有版式解析器。武汉校验标题月份、住宅列和分区合计；石家庄必须匹配请求月份，并核对分区和合计，不能将返回的其他月份当成请求月份。
- 首批人工核读的静态公告和PDF使用 `reviewed-snapshot`。其结构化字段与原文SHA256绑定，原文变更就转为待复核，不能将旧数字套入新文章。
- 上海近期网页普通HTTP读取返回403，通过官方公开网页阅读工具核读数值，使用 `reviewed-evidence`。数值摘录保留在 `docs/data/cities/evidence/`，与注册字段绑定校验；`evidenceSha256` 是摘录文件的哈希，`rawSha256` 保持null，不能冒充原始HTML快照。页面和CSV分别标注两类哈希。
- 原文、采集时间和哈希保存在本地 `backend/data/city-sources/`，该目录由Git忽略。网页保留公开来源链接、哈希和必要的数值摘录，不复制整篇官网文章或含脚本的HTML作为网页。
- 刷新失败保留上一版记录及其原采集时间，同时显示待复核状态，不将失败填为零。
- 只采公开汇总统计；不采个人合同、身份证、电话，不绕过验证码或动态防护。

依赖使用原有后端的 `requests`、`beautifulsoup4`、`lxml`。采集命令：

```sh
# 读取登记来源，保留原文；24小时内优先使用已校验缓存
python3 scripts/collect_city_data.py

# 重新读取原网站；人工核读来源若发生变化，须先审阅再更新注册表
python3 scripts/collect_city_data.py --refresh

# 发现并核对指定已结束月份的武汉、石家庄月表（每次最多36个月）
python3 scripts/discover_city_months.py --start 2025-01 --end 2026-09

# 仅从本地已保存原文及核读摘录重建
python3 scripts/collect_city_data.py --offline
```

这套城市资料发布管线与原有后端70城价格指数同步独立。它不改变70城价格指数的定义，不从价格指数推算元/㎡。没有创建定时任务。扩展城市时，应登记官方原始入口、期间、类型、单位与解析规则，再发布实际观察；仅找到入口不计入已有住宅交易城市数。

输出为 `data/cities/china-city-data.json` 及离线浏览器包 `china-city-data.js`。顶层分别保存城市覆盖、来源、观察、收入与可配对的年度收入比基准。分享链接只保存城市、记录、交易年份、年度收入基准年份、住宅类型及人数面积；CSV保留频率、来源、缺失值和子分组标记。

本次进行了真实官方资料采集、原表读取和脚本语法检查，没有运行测试套件，未进行原生浏览器交互或视觉验收。

## 历史覆盖核对

本轮补入北京2016—2023年统计销售住宅面积及多个历史城镇收入年份，北京2016—2025年均有年度面积记录；仅2024金额、面积及收入配齐。上海2016—2025十年同年基准齐全。深圳补入2022—2024年统计住宅面积，现有2022—2025年度面积；广州2020—2024年网签金额、面积保持独立口径。不同出版物可能保留不同修订版本，不用四舍五入的同比反推缺失原值。

页面新增2016—2025年四城40个城市年度的字段覆盖明细；交易年份可选择已有任一年或过去十年。该表区分面积、金额、收入与完整基准，缺项表示尚未取得可用数据，不表示官方确认未发布。

广州另按官方统计信息手册第33页补入2016—2024年城镇收入，与此前2025年收入形成十年序列。
